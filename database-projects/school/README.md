# مشروع نظام إدارة مدرسة

## المشكلة والحدود
يحفظ النظام الطلاب وأولياء الأمور والمعلمين والمواد والفصول والأعوام والتسجيل والحضور والاختبارات والدرجات. يحتفظ بالتاريخ الدراسي ولا يكتب فوق نتائج عام سابق.

## تسليمات المتعلم
حلّل العلاقة المباشرة وغير المباشرة بين الطالب والمعلم والمادة والدرجة، صمّم التسجيل وإسناد المعلم، امنع تعارض الحضور والدرجات، واكتب تقارير العام مع معايير قبول قابلة للاختبار.

# قاموس بيانات المدرسة

| الجدول | القرار |
|---|---|
| enrollments | الطالب لا يرتبط بالمعلم مباشرة؛ الارتباط يمر عبر الفصل والعام والإسناد |
| academic_years | العام جزء من الهوية التاريخية حتى لا نكتب فوق سجل سابق |
| teaching_assignments | كيان رابط يحمل سياق المعلم والمادة والفصل والعام |
| attendance | سجل يومي، والحالة الحالية وحدها لا تكفي للتقرير |
| assessments | الاختبار يحدد المادة والفصل والعام والحد الأعلى |
| grades | الدرجة تخص تقييمًا وتسجيلًا محددين مع قيد نطاق |

# مشروع نظام إدارة صيدلية

## المشكلة والحدود
يتابع النظام الأصناف والمواد الفعالة والموردين والدفعات والمخزون والمبيعات والمرتجعات والمدفوعات. لا يقدم تشخيصًا طبيًا ولا يقرر صلاحية الدواء سريريًا؛ هدفه سلامة المخزون والبيع والتتبع.

## تسليمات المتعلم
الوصف والأسئلة، حدود النظام، الأدوار، ERD، قاموس البيانات، القيود، seed، استعلامات التقارير، معاملة بيع تمنع بيع دفعة منتهية أو كمية غير موجودة، اختبار الحالات الحدية، وقرار تغيير متطلبات موثق.

# مشاريع مسار قواعد البيانات

تحتوي هذه المجلدات على ملفات تشغيل وتعليم للمشروعات الثلاثة. البيئة المستهدفة هي PostgreSQL 15+؛ يمكن تبسيط الأنواع لتوافق SQLite عند الحاجة، لكن `RETURNING` وبعض أنواع القيود والسلوكيات المتقدمة موضحة بصيغة PostgreSQL.

## ترتيب الاستخدام
1. ابدأ بوصف المشكلة والأسئلة في README الخاص بالمشروع.
2. راجع ERD قبل تشغيل `schema.sql`.
3. شغّل `seed.sql` بعد إنشاء الجداول.
4. جرّب `queries.sql`، ثم اكتب اختبارًا لحالة حدية قبل اعتبار المرحلة مكتملة.
5. لا تضع كلمات مرور حقيقية في ملفات seed أو المستودع.

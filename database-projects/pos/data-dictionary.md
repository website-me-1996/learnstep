# قاموس بيانات POS

| الجدول | القرار |
|---|---|
| products | الرصيد الحالي للحماية السريعة، مع إمكانية إضافة سجل حركة لاحقًا |
| register_sessions | الوردية وحدة تشغيل، وليست مجرد مستخدم |
| invoices | الفاتورة لا تُحذف؛ الإلغاء حالة مع سبب في سجل المراجعة |
| invoice_items | العلاقة بين الفاتورة والمنتج تحمل السعر وقت البيع |
| payments | أكثر من وسيلة دفع ممكنة للفاتورة نفسها |
| cash_movements | يفسر الفرق بين النقد الافتتاحي والنقد المتوقع |

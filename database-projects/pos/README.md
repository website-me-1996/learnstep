# مشروع نظام الكاشير POS

## المشكلة والحدود
يسجل النظام المنتجات والفواتير وتفاصيلها والمدفوعات وجلسة الكاشير والمخزون والمرتجعات وحركة الصندوق. الصلاحيات والتسويات جزء من النظام، أما جهاز الدفع الخارجي فهو خارج الحدود ويُحفظ أثر نتيجته فقط.

## تسليمات المتعلم
حلّل جلسة الوردية، ارسم العلاقات، أنشئ فاتورة متعددة الدفع داخل Transaction، امنع بيع آخر قطعة مرتين، أضف سبب الإلغاء والمرتجع، ثم اكتب تقارير الوردية وحالات القبول.
